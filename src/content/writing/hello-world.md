Medium is where my technical articles have lived so far. This site is where
everything else goes: shorter notes, CTF writeups that are too rough for a
publication, and the occasional post that isn't about computers at all.

Two kinds of posts live here:

- **Technical**: deep dives into how something works below the abstraction.
- **Notes**: shorter, more personal, less polished.

A footnote looks like this.[^1]

```c
for (int i = 0; i < 10; i++) {
    sum += i;   // one cmp, one jl, one add per iteration
}
```

[^1]: And it collects at the bottom of the post, like this.
